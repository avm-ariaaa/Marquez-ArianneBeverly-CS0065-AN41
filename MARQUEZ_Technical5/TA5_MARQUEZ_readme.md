## Project Overview

This project contains two Python Graphical User Interface (GUI) applications designed to perform Sentiment Analysis on user-provided text.



1. **Main Activity:** Uses the `TextBlob` NLP library to evaluate if a sentence is Positive, Negative, or Neutral, while keeping a running tally.
2. **Challenge Activity:** Uses a custom rule-based algorithm to count predefined "happy" and "sad" words to determine the overall tone of a sentence.



## Requirements \& Setup

* **Python 3.x** installed.
* **Tkinter** (comes pre-installed with standard Python).
* **TextBlob** library. Install it by running this command in your terminal:


  pip install textblob
  ```

## How to Run and Use



### Program 1: Main Activity (TextBlob)

1. Run the script: `python main\\\_activity.py` *(change filename if necessary)*.
2. **Usage:**

   * Type a sentence in the input box.
   * Press **<Enter>** or click **"Add New Sentence"**.
   * The app will log the sentiment and update the total counters automatically.
   * Use **"Enter New Sentence/s (Reset)"** to clear the log.



### Program 2: Challenge Activity (Custom Lexicon)

1. Run the script: `python challenge\\\_activity.py` *(change filename if necessary)*.
2. **Usage:**

   * Type a sentence in the input box.
   * Press **<Enter>** or click **"Analyze Tone"**.
   * A pop-up will display the exact number of happy/sad words and the final result.
   * Click **"Enter New Sentence"** to clear the input.
