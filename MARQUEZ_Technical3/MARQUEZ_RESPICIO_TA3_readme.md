## 📌 About This Project

This project is an **AI-Based Legal Decision Support System**. It demonstrates how a Case-Based Reasoning (CBR) system works by:
1. **Retrieving** past legal cases that are most similar to a new client's issue.
2. **Adapting** the legal arguments from the past case to fit the new situation.
3. **Retaining** the new case in the system's memory for future use.

## 📂 Files Included

* `TA3_Marquez_Respicio.py`: The main Python program. It includes the case base, the CBR logic, and a graphical user interface (GUI) built with Tkinter.
* `TA3_Marquez_Respicio.pdf`: The complete project documentation, including code explanations, screenshots, and our pair programming reflection.

## 🛠️ How to Run

1. Make sure you have Python installed on your computer.
2. Download or clone this repository.
3. Open your terminal or command prompt in this folder.
4. Run the following command:
   ```bash
   python TA3_Marquez_Respicio.py
   ```
5. A window will pop up showing the legal system's reasoning process and output.
